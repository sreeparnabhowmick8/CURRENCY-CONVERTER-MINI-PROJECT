# Currency Converter 💱

A simple and interactive **Currency Converter Desktop Application** developed using **Java Swing** and **AWT**. This project allows users to convert currencies between multiple countries using predefined exchange rates through a user-friendly graphical interface.

## Features

* Convert currencies between multiple countries
* Easy-to-use GUI interface
* Real-time currency conversion
* Input validation with error handling
* Reset and Exit functionality
* Built using Java Swing components

## Technologies Used

* Java
* Swing
* AWT
* HashMap
* Event Handling

## Supported Currencies

* USD
* EUR
* INR
* GBP
* AUD
* CAD
* AED
* HTG
* JPY
* NPR
* BDT

## How It Works

1. Select the source currency
2. Enter the amount
3. Select the target currency
4. Click the **Convert** button to get the converted value
